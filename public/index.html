使用区

无会话

安装步骤

  1. 在下方节点列表中添加 HTTP / HTTPS / SOCKS5 代理节点。
  2. 选择节点和有效期，点击“生成临时 CRX”。
  3. 在 Chrome 的 chrome://extensions 打开开发者模式，手动安装下载的 CRX。
  4. 若 CRX 被 Windows/macOS 限制，下载 ZIP，解压后在开发者模式下“加载已解压的扩展程序”。
  5. 页面关闭会尽力撤销会话；最终由服务端 TTL / 空闲超时兜底。

注意：CRX 下载文件可能留在下载目录；扩展自卸载不能保证删除下载文件。Chrome 代理设置仅作用于浏览器，不等于系统所有程序都走代理。

临时代理会话

无会话

CRX 中的 token 是一次性的：第一次心跳后立即被服务端轮换，旧 token 永久失效。 会话结束后所有 token 都会失效，下载的安装包无法再次使用。

安装步骤

  1. 选择节点和有效期，生成临时 CRX。
  2. Chrome 打开 chrome://extensions，开启开发者模式，手动安装 CRX。
  3. 被 Windows/macOS 限制时，下载 ZIP，解压后“加载已解压的扩展程序”。
  4. 扩展每 15 秒心跳一次；页面关闭 / 主动关闭 / 超时后自动恢复代理并卸载。

注意：Chrome 代理设置仅作用于浏览器，不等于系统所有程序都走代理； CRX 下载文件可能留在下载目录，扩展自卸载不会删除它。
